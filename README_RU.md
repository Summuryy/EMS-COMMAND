# EMS COMMAND v3.2 — Installer Studio

## Для игрока
**Одна установка, один ярлык.** Разработчик собирает `EMS-COMMAND-Setup-3.2.0.exe` в GitHub Actions на Windows. После сборки игроку достаточно запустить EXE, выбрать папку и завершить установку. Electron и сервер входят в приложение. Node.js, `.bat` и npm игроку не требуются.

Окно лаунчера открывается отдельно от браузера. При первом запуске создаётся администратор. Данные и настройки сохраняются в пользовательской папке вне директории приложения.

## Что обновлено
- Перерисованные ресурсы NSIS-установщика: вертикальная бренд-панель и заголовок, красно-графитовая палитра госбольницы RP, медицинская кардиограмма.
- Более понятный мастер первой настройки.
- Живой центр обновлений: состояние, установленная версия, фактический процент загрузки, контекстные кнопки. На сообщения из Electron подписан интерфейс; обновления без фида не имитируются.
- Безопасное экранирование информации об обновлениях, ограничение диапазона процентов, тесты.
- Тесты больше не привязаны к `/mnt/data`: опциональный `EMS_TEST_FIXTURES` задаёт собственные скриншоты разработчика.
- При сборке не включаются базы SQLite, логи, BAT-файлы и локальные скриншоты.

## Как собрать установщик
1. Поместить исходники в приватный `Summuryy/EMS-COMMAND` (не загружать .env и данные пользователей).
2. GitHub → **Actions → Windows installer (test build) → Run workflow**.
3. После выполнения скачать артефакт `EMS-COMMAND-Windows-Installer-UNSIGNED`.
4. Проверить установку/удаление/повторное открытие на Windows 10/11.

## Ограничения
Архив — **исходники**, не собранный Windows EXE. В этой Linux-среде проверены Node-тесты и ресурсы BMP, но Windows/NSIS в реальной среде должен пройти проверку GitHub Actions. Подписи издателя пока нет: неподписанный EXE может вызвать SmartScreen; отключать защиту не рекомендуется.

Автообновление работает после публикации HTTPS-фида с корректными подписанными релизами, а `desktop/release-config.json` по умолчанию намеренно пуст. **Частный GitHub репозиторий не является публичным каналом обновлений**. Никаких реальных платных подписок и событийного автозахвата пока не подключено. OCR может требовать системный Tesseract.
