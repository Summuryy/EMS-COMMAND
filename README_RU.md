# EMS COMMAND v3.3 — Launcher + Motion

## Что изменилось
- Фирменный полноэкранный экран запуска (в отдельном Electron-окне), анимированный пульс и индикатор запуска.
- Непрерывная анимация ECG на страницах, усиленные индикаторы и мягкие реакции элементов интерфейса.
- Установленное приложение проверяет обновления при запуске и автоматически **скачивает** подписанное обновление, если настроен HTTPS-канал релизов. Установка — только после согласия пользователя.
- База SQLite и доказательства хранятся отдельно от устанавливаемого приложения.

## Ключевая техническая оговорка
Этот ZIP — **исходный проект**, а не готовый исполняемый файл. На Windows GitHub Actions можно собрать EMS-COMMAND-Setup-3.3.0.exe, который используется один раз для первоначальной установки. В дальнейшем обновления устанавливаются **из лаунчера**, без ручного открытия установщика.

Для полноценной работы обновлений необходим отдельный доступный пользователям HTTPS feed с подписанными сборками и файлами `latest.yml`; заполните `desktop/release-config.json` до выпуска подписанной сборки. У приватного GitHub-репозитория нет анонимной загрузки релизов: нельзя вставлять личный GitHub-токен в приложение. Сейчас `feedUrl` пустой, и автообновление честно обозначается как недоступное.

## Сборка Windows
1. Загрузите исходники в закрытый репозиторий GitHub.
2. Запустите Windows installer (test build) в Actions. Он проверит исходники и создаст неподписанный тестовый EXE.
3. Скачайте артефакт из workflow; прежде чем раздавать его другим пользователям, проверьте установку и безопасность на Windows.
4. Для релизов настройте code signing и публичный HTTPS feed. Не публикуйте ключ подписи в репозитории.

## Для пользователя
При первом запуске откроется экран EMS COMMAND Launcher, затем приложение. Нет необходимости открывать Opera. Все пользовательские данные и пароли хранятся локально. Событийный PRO-захват и платежи по-прежнему находятся в разработке.

## Анимации
Работают на всех разделах, если в профиле включено «Анимации» и в Windows не выбрано «Уменьшить движение». Индикаторы обновления показывают только реальные события, никаких фиктивных процентов.
