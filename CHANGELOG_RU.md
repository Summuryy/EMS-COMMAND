# v3.14.0 — Постоянный прогресс Академии (preview)

- Личные отметки и последний открытый учебный шаг теперь сохраняются в SQLite-базе аккаунта в постоянной папке данных EMS COMMAND, не зависящей от случайного localhost-порта Electron.
- Добавлена неразрушающая таблица `academy_state`, персональные маршруты GET/POST с сессией и CSRF, проверкой существующих учебных ключей и ограничением запросов.
- Отметки сохраняются индивидуально и последовательно; при смене аккаунта данные не смешиваются. Серверный прогресс всегда важнее устаревшей локальной копии.
- Одноразовый импорт старых отметок с текущего доступного адреса приложения. Данные других, недоступных локальных портов импортировать автоматически нельзя.
- При недоступном сервере интерфейс явно показывает локальный режим или ошибку сохранения, не выдавая локальные отметки за защищённые данные аккаунта.
- Сохранены 12 курсов, 70 шагов, 25 встроенных игровых WebP, сортировка, галерея, обучающие материалы, существующие отчёты и система подписанных обновлений.
- Проверки: 97/97 тестов, Windows NSIS smoke-install и Portable Launcher Windows QA. Устойчивое хранение после рестарта проверено также отдельным тестом со вторым процессом SQLite.
- Версия для тестирования владельцем; официальный запуск не объявлялся.

# v3.13.0 — Оптимизация Академии и навигации (preview)

- Изображения скрытых шагов больше не назначают src и не запрашиваются заранее; при переходе на шаг загружаются только его фотографии, все 25 встроенных WebP сохранены.
- Поиск по 12 курсам использует заранее подготовленный индекс и небольшую задержку ввода (90 мс) вместо повторного обхода всего DOM.
- При открытии Академии убрана вторая полная перерисовка интерфейса и лишний запрос уведомлений.
- При навигации по другим разделам после получения данных сервера обновляется только содержимое страницы; боковое меню и верхняя панель остаются на месте.
- Шкала текущей смены больше не обновляет DOM вне экрана «Моя смена».
- Регрессионные тесты проверяют отложенную загрузку, безопасность локальных путей, совместимость сохранённого прогресса и экономию перерисовок.
- QA: 92/92 автоматических теста, Windows NSIS smoke-install и Portable Launcher Windows QA успешно завершены.
- Исправлены подтверждённые по исходникам избыточные операции. Фактическое изменение FPS на компьютере пользователя пока не измерено.
- Подписанный preview распространяется через существующий единый лаунчер; официальный запуск продукта не объявлялся.
