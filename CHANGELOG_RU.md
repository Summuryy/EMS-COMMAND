# v3.11.0 — Визуальная Академия (preview)

- 25 отобранных кадров из игровых инструкций России Онлайн теперь встроены непосредственно в Windows-приложение (offline WebP).
- Пошаговое обучение интернатуры, ОМП, ОПП, ПМП и выдачи таблеток дополнено иллюстрациями по месту действия.
- Маршрут в Правительстве, кабинеты №204/205, меню реанимации и СГУ, автомобиль скорой и зоны регистратуры в двух больницах.
- Поиск по урокам, фильтры по категориям, полноэкранный просмотр изображений, поддержка клавиатуры и уменьшенного движения.
- Сохранена локальная история выполнения шагов каждого профиля без сброса после обновления.
- Встроенные WebP проверяются тестами: точные имена, формат и границы каталога. Исходные 79 скриншотов остаются отдельно в личной библиотеке.
- Подписанное preview-обновление доставляется через действующий единый лаунчер после успешной публикации; официальный запуск не объявлялся.

# v3.3.0 — Launcher + Motion

- Переделан стартовый экран Electron в полноценный фирменный launcher splash.
- Непрерывная движущаяся линия ECG вместо почти незаметной анимации одного штриха.
- Мягкие световые сигналы навигации и статусов, динамическая подсветка кнопок и карточек во всех разделах.
- Автоматическая загрузка доступных подписанных обновлений при подключённом канале; установка только по подтверждению.
- Явное указание статуса неподключённого канала релизов, без имитации работающего автообновления.
