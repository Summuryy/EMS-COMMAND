# Архитектура EMS COMMAND Launcher — план релизов

**Цель:** один ярлык EMS COMMAND и обновление внутри приложения, без ручного скачивания следующих установщиков.

## v3.3
- Встроен стартовый экран лаунчера, локальный backend и центр обновлений.
- При настроенном защищённом HTTPS-канале `electron-updater` проверяет и автоматически скачивает доступные обновления, отображая реальный процент.
- Перезапуск и установка — только после согласия пользователя, чтобы не прервать смену.
- Пользовательские базы и скриншоты находятся вне каталога программы.
- **Публичный feed пока отсутствует. Реальное обновление версии из GitHub пока недоступно.**

## Что требуется до рабочего канала
1. Публично доступный HTTPS-хостинг подписанных релизов и метаданных `latest.yml` (или отдельный публичный репозиторий релизов); исходники продолжают жить в приватном репозитории.
2. Подпись Windows-сборок и безопасное управление ключами через CI secrets.
3. Тестовое обновление с предыдущей версии, резервирование и миграции базы, проверка неудачной установки и восстановления.
4. Публикация только стабильных версий после CI, не после любого коммита.
5. Никаких GitHub токенов в приложении и никаких неподписанных исполняемых файлов из сети.

## Первый запуск
Первый EXE нужен для доставки самого лаунчера на Windows **один раз**. В последующих версиях обновление выполняется внутри EMS COMMAND. Полностью переносимая модель, где лаунчер устанавливает само приложение без NSIS, требует отдельного безопасного менеджера пакетов и пока не реализована.
