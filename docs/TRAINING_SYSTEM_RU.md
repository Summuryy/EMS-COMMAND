# EMS COMMAND 3.10 — академия госбольницы (Россия Онлайн)

Это документация **учебной функции**, не официальный регламент. Приоритет всегда у актуальных закреплённых сообщений руководства и правил сервера. Исходники и пользовательские доказательства не являются взаимозаменяемыми.

## Что получит сотрудник

- Пятнадцать последовательных уроков для нового сотрудника, интерна, ОМП, ОПП и квалифицированных врачей: удостоверение, трудоустройство, инструктаж, проверки, ПМП, таблетки, дежурства, вакцинация, медкарты, операции, кадровый аудит и недельные отчёты.
- Три отдельные таблицы карьерных нормативов: Интернатура 1→3, ОМП 5→9, ОПП 3→9. Правило ОПП «80% ПМП вне больницы» не применяется к другим отделам.
- Копируемый шаблон отчёта интерна 1→2 и 2→3 с обязательным упоминанием ОМП, проверкой разрешённых фотохостингов и заметными пустыми полями. Автоматической отправки, утверждения или признания кадровых документов нет.
- Генератор текста /gnews с выбираемым временем. Выдержка 15 минут и факт одобрения проверяются человеком.
- Галереи с пользовательскими игровыми скриншотами: после выбора оригинальных файлов на устройстве изображения отображаются в нужных уроках. Пример *не* становится доказательством реальной работы.

## Где код

`public/js/views/training-data.js` — учебные сценарии, нормативы, ссылки, версии. `training.js` — интерфейс в существующей Академии. `training-interactions.js` — поиск, фильтры, безопасный локальный выбор скриншотов, тексты для копирования. `public/styles/v3/training310.css` — стили и адаптивность. `tests/training310.test.mjs` — проверки регламентов и интерфейса.

Существующий `public/js/views/academy.js` продолжает показывать и искать устав. Ни один backend endpoint, модель доказательств, пользователя, прав, электронная подпись или лаунчер не изменялись.

Владелец передал 79 PNG-кадров. **Не размещать их в репозитории, публичных GitHub Releases, npm-пакете, логах или публичном CDN.** Некоторые кадры содержат имена/Static ID и переписку. Архив с оригиналами и каталогом сохранён в приватной библиотеке владельца: `/EMS COMMAND/Training-2026-11-12/EMS_COMMAND_Training_Images_2026-11-12.zip`.

Чтобы видеть изображения: распаковать ZIP → в Академии нажать «Выбрать скриншоты» → выделить PNG внутри `screenshots/`. Файлы не отправляются в интернет, используются в пределах текущего сеанса. После рестарта выбор необходимо повторить. В будущем можно реализовать *отдельно согласованное* постоянное локальное хранение с безопасной проверкой, без вмешательства в данные пользователя/подписанный пакет.

Полный справочник владельца для следующих чатов — файл `EMS_TRAINING_KNOWLEDGE_2026-11-12.md` в этой же приватной библиотеке. Не приписывайте себе его прочтение, пока не получили файл через Files. В этом репозитории хранится только учебный код и краткое описание архитектуры.
